Dispatch 是什么？—中文解释

dispatch (派发) 就是把“一封 Action 信”交到 Redux 邮局（store）窗口，让 Redux 去处理这封信并更新全局 state。
你可以把它想成：
“我有个请求，请 Redux 处理并更新数据，然后通知界面重绘。”

⸻

完整流程（用你的按钮示例）—English walk-through

<Button onClick={() => dispatch(deleteTodo(todo.id))}>Delete</Button>

	1.	User click
The onClick handler runs.
	2.	Action-creator runs

deleteTodo(todo.id)

returns an action object:

{
  type: "todos/deleteTodo",   // auto-generated by createSlice
  payload: "2"                // the id you passed
}


	3.	Dispatch sends the action to the store

dispatch({ type:"todos/deleteTodo", payload:"2" })


	4.	Store forwards the action to the root-reducer
configureStore internally created a big reducer combining all slice reducers.
	5.	Root-reducer finds the matching slice
Because the action type starts with "todos/", Redux calls todosReducer (your slice’s reducer) and passes it:

currentSliceState   // state.todos right now
action              // { type:"todos/deleteTodo", payload:"2" }


	6.	todosReducer executes the correct case
Inside the slice you wrote:

deleteTodo: (state, action) => {
  state.todos = state.todos.filter(t => t.id !== action.payload);
}

Immer produces an immutable copy where that row is removed.

	7.	Store saves the new state
The root state is now updated.
	8.	React components re-render
Any component that used

const todos = useSelector(s => s.todos.todos);

receives the new array and updates the UI.

So “dispatch” is simply step 3—shipping the action object to Redux; Redux then routes it to the proper reducer, which computes the next state version.
