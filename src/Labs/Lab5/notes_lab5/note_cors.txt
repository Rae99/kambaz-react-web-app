1. Does “origin” mean the same thing in CORS and in Git?

No—they’re completely different concepts, just the same word!

In Web Browsers / CORS:
	•	Origin means:
protocol + domain + port
For example:

	•	http://localhost:5173
	•	https://example.com:443
	•	Browsers use “origin” to define what counts as “the same place” for security reasons.
	•	If you change any of the three (protocol, domain, or port), you have a new origin.

2. 
In Git:
	•	Origin is just the default name given to the remote repository you cloned from.
	•	When you run git clone, Git remembers where you cloned from and labels it as origin.
	•	It could be GitHub, GitLab, or any remote repo.
